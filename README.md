# Qarro Live Translator v0.3

Android-компаньон + локальный Python gateway для перевода речи из воспроизводимого аудио в русский дубляж и субтитры.

## Что работает в кодовой базе v0.3

### ⚡ Live
- захват разрешённого Android playback audio через `AudioPlaybackCapture`;
- 48 kHz mono PCM16 → 24 kHz mono PCM16;
- поток в `gpt-realtime-translate`;
- автоматическое определение исходного языка моделью;
- русский перевод аудио + русские субтитры;
- защита от сетевого backlog: старые входные блоки не копятся бесконечно.

### 🎭 Multi-voice
- чанки 3–12 секунд;
- `gpt-4o-transcribe-diarize` для разделения говорящих;
- до четырёх готовых speaker-reference передаются обратно diarizer-у;
- банк до 8 профилей Speaker A…H, чтобы шум не создавал бесконечные ложные профили;
- постоянный TTS-voice закрепляется за speaker profile;
- перевод + оценка эмоциональной подачи;
- `gpt-4o-mini-tts` озвучивает реплику выбранным голосом и стилем;
- сервер отправляет метрики времени обработки и очереди.

> Важно: v0.3 **не клонирует оригинальный голос** и пока не переносит исходную просодию/эмоцию 1:1. Эмоциональная подача определяется по тексту + акустической энергии и передаётся в TTS как инструкция. Это промежуточный этап перед аудио-анализом эмоций.

## Что нового по сравнению с v0.2

- кнопка **«Проверить сервер»** в Android;
- проверка версии сервера и наличия `OPENAI_API_KEY`;
- громкость русского дубляжа 0–100%;
- опция Audio Focus для просьбы Android приглушить оригинал;
- WebSocket backpressure guard, чтобы не накапливать огромную задержку;
- ограничение ложного роста speaker profiles;
- метрики Multi-voice pipeline;
- корректное закрытие upstream Realtime WebSocket;
- `.env.example` больше не содержит ключ-плейсхолдер, который можно ошибочно принять за рабочий;
- 9 серверных тестов;
- отдельный GitHub Actions workflow для Python tests;
- GitHub Actions workflow для debug APK;
- скрипт полной локальной проверки проекта.

## Сборка APK

Репозиторий содержит `.github/workflows/android-debug-apk.yml`. После загрузки проекта в GitHub открой **Actions → Build Android Debug APK → Run workflow**. Готовый `app-debug.apk` будет лежать в artifact `QarroLiveTranslator-v0.3-debug-apk`.

Локально можно выполнить:

```bash
./scripts/build_android_debug.sh
```

Для этого нужны Android SDK и Gradle.

## Ограничения Android / YouTube

`AudioPlaybackCapture` работает только для аудио, которое приложение-источник разрешает захватывать. Если конкретная версия YouTube или устройство запрещает capture, Qarro Live Translator не может обойти эту политику через официальный Android API.

Stock YouTube также нельзя искусственно задержать из companion-приложения. Поэтому:

- **Live** предназначен для минимальной фактической задержки поверх обычного YouTube;
- полноценный **Buffered Dub** потребует контролируемого плеера и остаётся следующим большим этапом.

## Безопасность ключа

`OPENAI_API_KEY` хранится только на gateway/server и не должен встраиваться в APK. Файл `server/.env` исключён из Git.
