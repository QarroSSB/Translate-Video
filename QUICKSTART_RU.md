# Qarro Live Translator v0.3 — быстрый запуск

## 1. Сервер

На компьютере распакуй проект.

### Windows

1. Открой `server/.env.example`.
2. Скопируй его как `server/.env`.
3. Впиши ключ:

```text
OPENAI_API_KEY=твой_ключ
```

4. Запусти:

```bat
scripts\run_server_windows.bat
```

### Linux / macOS

```bash
cp server/.env.example server/.env
```

Впиши `OPENAI_API_KEY`, затем:

```bash
./scripts/run_server_linux_macos.sh
```

Сервер слушает порт `8765`.

Проверка на компьютере:

```text
http://127.0.0.1:8765/health
```

Должно быть `"ok": true` и `"api_key_configured": true`.

## 2. Android

После сборки и установки APK:

1. Телефон и компьютер должны видеть друг друга по сети.
2. Узнай локальный IP компьютера, например `192.168.1.25`.
3. В приложении укажи:

```text
ws://192.168.1.25:8765/ws/translate
```

4. Нажми **«Проверить сервер»**.
5. Если увидишь `сервер v0.3.0 готов • API key ✓`, соединение настроено.
6. Выбери:
   - **Live** — быстрее;
   - **Multi-voice** — разные голоса/эмоциональная подача, но выше задержка.
7. Настрой громкость русского голоса.
8. При желании включи просьбу приглушать оригинальный звук.
9. Если нужны субтитры поверх YouTube — выдай разрешение overlay.
10. Нажми **«Начать перевод»** и подтверди системное разрешение захвата экрана/аудио.
11. Открой YouTube и включи ролик.

## 3. Если звук не переводится

Если через примерно 5 секунд приложение сообщает, что входной звук не обнаружен, наиболее вероятно, что приложение-источник не разрешило `AudioPlaybackCapture` на этом устройстве/версии.

Если сервер недоступен:
- проверь IP компьютера;
- убедись, что порт 8765 не блокирует firewall;
- не используй `10.0.2.2` на физическом телефоне — это адрес хоста Android Emulator;
- нажми **«Проверить сервер»** ещё раз после исправления адреса.

## 4. Проверить исходники

Из корня проекта:

```bash
./scripts/verify_project.sh
```

Проверяются Python syntax/tests, Android XML и отсутствие случайно сохранённого API key.
